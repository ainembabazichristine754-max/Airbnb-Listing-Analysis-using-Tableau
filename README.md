Airbnb Listings Analysis Using Tableau
Project Background

I worked on an Airbnb listings dataset to understand how prices vary across different properties and locations.

The analysis focuses on bedrooms, zip codes, and revenue trends to identify factors that influence Airbnb pricing.

The dashboard was built in Tableau and is designed to provide quick insights into pricing patterns across the market.

Objectives

The project aimed to answer the following questions:

How does the number of bedrooms affect Airbnb prices?
Which zip codes have the highest average listing prices?
How many listings exist for each bedroom category?
How does revenue change throughout the year?
Which areas may offer better opportunities for Airbnb hosts?

Key Findings
1. Bedroom Count Drives Pricing

Properties with more bedrooms generally command higher prices.

Average prices increased from approximately $91 for one-bedroom properties to approximately $576 for six-bedroom properties.

2. Most Listings Are Small Properties

The market is heavily concentrated around one-bedroom listings.

This suggests strong demand for smaller and more affordable accommodation options.

3. Location Influences Price

Certain zip codes consistently achieve higher average prices than others.

Hosts operating in premium locations have greater pricing potential.

4. Revenue Shows Seasonal Patterns

Revenue grew rapidly early in the year before stabilising.

This suggests seasonal demand may influence Airbnb performance.

Recommendations
For Airbnb Hosts
Consider adding capacity where possible since larger properties achieve higher average prices.
Review pricing strategies against nearby zip codes.
Monitor seasonal demand when setting prices.
For Investors
Focus on high-performing zip codes with strong pricing potential.
Evaluate bedroom count when assessing potential Airbnb investments.
